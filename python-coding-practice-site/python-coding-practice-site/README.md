# Python コーディング課題

篠崎中学校チャレンジクラス向けの、GitHub Pagesで公開できる静的ページです。
print・変数・再代入・f文字列を使う基本6問とチャレンジ2問を掲載しています。

## 公開するファイル

- `index.html`：全8問の問題文、出力例、f文字列ガイド
- `styles.css`：PC・iPad・スマートフォン向けの表示
- `app.js`：1問ずつ表示する切り替え機能
- `favicon.svg`：ページのアイコン
- `.nojekyll`：GitHub Pages用の設定

ビルドやnpmのインストールは不要です。すべてのパスは相対パスです。
GitHub Pagesのリポジトリ配下でも、そのまま動作します。
JavaScriptを無効にした場合は、全問を縦に並べて表示します。

## まず手元で確認する

ZIPを展開し、`index.html`をブラウザーで開いてください。
HTML・CSS・JavaScript・アイコンは同じフォルダーに置いてください。

## GitHub Pagesで公開する

このZIPを渡した時点では、GitHubのリポジトリ編集や公開操作は行っていません。
既存の授業ページを残すなら、**新しいリポジトリ**か**新しいサブフォルダー**に、上記のファイルを配置してください。
既存の`index.html`を置き換える必要はありません。

新しいリポジトリの場合は、GitHubの「Settings → Pages」で公開元のブランチとフォルダーを選びます。
すでに公開中のリポジトリにサブフォルダーを作る場合は、そのサブフォルダーをURLの末尾に付けて開きます。
ZIPそのものではなく、展開したファイルを配置してください。

## 掲載内容・機能

- 問1〜問8の一覧から、読みたい問題へ切り替え
- 「前の問題」「次の問題」で移動
- URLの末尾に`#q5`などを付けて、特定の問題を直接表示
- 問5に、開いた状態のf文字列ガイド
- 各問の「完成したら」の追加課題
- TechNexusを新しいタブで開くリンク
- 印刷時は、全8問を表示

確認テスト、採点、解答表示、コード実行機能はありません。
生徒の名前・アカウント情報は収集しません。
外部フォント・外部JavaScript・アクセス解析・Cookie・localStorageは使用していません。

## 問題文を変更する

`index.html`内の`<article id="q1">`〜`<article id="q8">`を編集してください。
出力例は、各問題の`<pre class="output"><code>…</code></pre>`にあります。
問6の「直すコード」は、意図的に閉じかっこが1つ足りない状態です。

## 開発用の確認

Node.jsが使える場合、次のコマンドで問題切り替えの確認を実行できます。

```sh
node --test tests/navigation.test.cjs
```

`tests`フォルダーとこのREADMEは、公開に必須ではありません。
