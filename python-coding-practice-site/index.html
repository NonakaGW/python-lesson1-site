問5再代入 · f文字列基本

変数の中身を変更する

ここから使うf文字列ガイド

f文字列を使うと、文章の中に変数の中身を入れて表示できます。

文字列の前にfを付けて、文章に入れたい変数名を{ }で囲みます。

{ }は半角の波かっこです。文字列だけでなく、数値が入った変数も同じように使えます。

詳しくは、第2回の授業資料も確認してみましょう。

コード例

food = "りんご"
print(f"好きな食べ物は{food}です")

実行結果

好きな食べ物はりんごです

やること

装備を変更するプログラムを、次の手順で作りなさい。

  1. weaponという変数に、文字列の「剣」を入れる。
  2. f文字列を使って、「装備は剣です」と表示する。
  3. 同じ変数weaponに、文字列の「弓」を入れ直す。
  4. f文字列を使って、「装備は弓です」と表示する。

「剣」「弓」の部分は、文章に直接書かず、変数weaponを使ってください。

実行例

装備は剣です
装備は弓です

完成したら

2回目に変数へ入れる文字列を「杖」に変更して、2行目だけが変わることを確かめましょう。
