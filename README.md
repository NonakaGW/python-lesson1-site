# プログラミング第1回 オンライン教室

中学校で行う「プログラミング第1回」のオンライン参加者向けサイトです。

## できること

- 授業資料（PDF）の閲覧・保存
- 問1〜7の人間プログラミング（細分化カードを命令ごとに1行表示＋インデント方式）
- 9問の確認テストと自動採点

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダの中身を、そのリポジトリの一番上へアップロードします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Deploy from a branch` を選び、`main` と `/(root)` を指定して保存します。
5. 数分後に表示されるURLをiPadで開きます。

ビルド作業や外部サービスの設定は不要です。

## ファイル構成

- `index.html`：画面の構造
- `styles.css`：デザインとiPad対応
- `app.mjs`：画面操作・アニメーション
- `game-core.mjs`：人間プログラミングの判定処理
- `quiz-core.mjs`：確認テストの採点処理
- `assets/lesson-1.pdf`：授業資料
